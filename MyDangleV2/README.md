# MyDangle V2

1. Open MyDangleV2.xcodeproj.
2. Select My Mac.
3. Choose your Apple Development Team if Xcode asks.
4. Press Command + R.
5. Wait about a second.
6. Look for `🧿 MyDangle` in the menu bar.
7. The charm should hang from the top center.

Everything runs locally. No external packages or server are used.
